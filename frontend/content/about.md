## 关于这个站

一个没有后台的静态博客。文章是仓库里的一堆 Markdown 文件，推送之后由 GitHub Actions 自动构建发布。

之所以做成这样，是因为原来那套 Spring Boot + Vue 的方案，每次想写点东西都得先启动服务、打开网页、登录、点新建——光是这一串动作就足够让人放弃了。

现在只需要打开编辑器，新建一个 `.md`。
