这个博客没有后台，也没有登录框。写文章 = 新建一个文件。

## 第一步：建文件

在 `frontend/content/posts/` 下新建一个 `.md` 文件，文件名就是文章的网址：

```text
frontend/content/posts/my-first-post.md
        ↓
https://你的域名/#/post/my-first-post
```

建议用小写英文加连字符，别用中文和空格。文件名定了就尽量别改，改了旧链接会失效。

## 第二步：写头部

文件开头两块 `---` 之间是文章的元信息：

```yaml
---
title: 文章标题
date: 2026-10-28
tags: [随笔, 生活]
summary: 列表页显示的一段摘要，一两句话就够。
---
```

四个字段都可以省：

| 字段 | 作用 | 省略后 |
| --- | --- | --- |
| `title` | 标题 | 用文件名 |
| `date` | 发布时间，决定排序 | 1970-01-01，会沉到最底 |
| `tags` | 标签，支持 `[a, b]` 或分行 `- a` | 无标签 |
| `summary` | 列表页摘要 | 自动截取正文前 110 字 |
| `draft` | 设为 `true` 则构建时跳过 | 正常发布 |

日期格式写 `2026-10-28` 就行，也可以带上时间 `2026-10-28 14:30`。

## 第三步：写正文

`---` 下面全部是正文，标准 Markdown 语法。标题从 `##` 开始用，`#` 留给文章标题本身。

## 第四步：预览

```bash
cd frontend
npm run dev
```

打开终端里给出的地址，改文件会自动热更新。

## 第五步：发布

```bash
git add .
git commit -m "post: 我的第一篇文章"
git push
```

推到 `main` 分支后，GitHub Actions 会自动构建并发布，一两分钟后线上就能看到。

## 几个约定

**图片**：放在 `frontend/public/images/` 下，正文里用绝对路径引用，构建时会自动补上仓库子路径。

```markdown
![示意图](/images/demo.png)
```

**代码块**：三个反引号后面写上语言名，会有语法高亮。

**别在正文里写 `#` 一级标题**：页面已经渲染了标题，再来一个会重复。

**长文章**：超过两三屏的，用 `##` 分节，阅读体验会好很多。
